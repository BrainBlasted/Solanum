# Installing Solanum from Source

This guide explains how to build and install Solanum locally for both **Development** and **Production (Non-Dev)** modes.

---

## Key Requirements & Guidelines

- **Meson + Cargo**: Solanum compiles Rust via Cargo wrapped inside Meson (`src/config.rs` requires env constants and GResource bundles generated by Meson). **Do not run `cargo build` directly.**
- **Blueprint Compiler**: System `blueprint-compiler` must be used (`--wrap-mode=nofallback`).
- **Sudo with Rustup**: When running `sudo ninja install`, pass `RUSTUP_HOME` if Rust was installed via `rustup` under your user home directory: `sudo RUSTUP_HOME=$HOME/.rustup ninja -C _build install`.
- **Single-Instance Application**: Solanum runs as a single-instance GTK `AdwApplication`. Before launching a newly installed binary, terminate any existing running background process using `killall -9 solanum`.

---

## 1. Development Build (`-Dprofile=development`)

* **App ID**: `org.gnome.Solanum.Devel`
* **Titlebar**: Features a striped hazard banner (`.devel` class) indicating a development build.

### Setup & Build
```bash
meson setup _build --wrap-mode=nofallback -Dprofile=development
ninja -C _build
```

### Install & Run
```bash
sudo RUSTUP_HOME=$HOME/.rustup ninja -C _build install
killall -9 solanum 2>/dev/null
solanum
```

---

## 2. Production / Non-Dev Build (`-Dprofile=default`)

* **App ID**: `org.gnome.Solanum`
* **Titlebar**: Standard, clean GNOME window headerbar (no striped pattern).

### Setup & Build
If `_build` was already configured, reconfigure it with the `default` profile:
```bash
meson setup --reconfigure _build -Dprofile=default --wrap-mode=nofallback
ninja -C _build
```

If setting up for the first time:
```bash
meson setup _build --wrap-mode=nofallback -Dprofile=default
ninja -C _build
```

### Install & Run
```bash
sudo RUSTUP_HOME=$HOME/.rustup ninja -C _build install
killall -9 solanum 2>/dev/null
solanum
```

---

## 3. Switching Profiles Quick Reference

```bash
# Switch to Production (Clean Titlebar):
meson setup --reconfigure _build -Dprofile=default
ninja -C _build
sudo RUSTUP_HOME=$HOME/.rustup ninja -C _build install

# Switch to Development (Striped Titlebar):
meson setup --reconfigure _build -Dprofile=development
ninja -C _build
sudo RUSTUP_HOME=$HOME/.rustup ninja -C _build install
```

---

## 4. Running Validation Tests

```bash
meson test -C _build
```
